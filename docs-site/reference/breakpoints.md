# 断点

六档宽度、三端形态。Less 变量给样式用，`BREAKPOINTS` 常量给脚本用，两边的数值必须一一对应。

## 六档

| 档位  | 宽度区间    | 形态 | 典型设备       |
| ----- | ----------- | ---- | -------------- |
| `xs`  | < 480       | 手机 | 竖持小屏       |
| `sm`  | 480 – 639   | 手机 | 竖持大屏       |
| `md`  | 640 – 767   | 手机 | 横屏手机       |
| `lg`  | 768 – 1023  | 平板 | 竖持平板       |
| `xl`  | 1024 – 1199 | 平板 | 横持平板       |
| `2xl` | ≥ 1200      | 桌面 | 笔记本与显示器 |

Less 侧对应 `@screen-xs: 479px`、`@screen-sm: 639px`、`@screen-md: 767px`、`@screen-lg: 1023px`、`@screen-xl: 1199px`、`@screen-2xl: 1599px`，区间取半开：`width ≤ 767` 即手机端。

## 三端

`xs / sm / md` 归手机端，`lg / xl` 归平板端，`2xl` 归桌面端。样式里用两个聚合变量就够了：`@mobile-max: 767px`、`@tablet-max: 1199px`。

```ts
import { useBreakpoint } from "@/composables/use-breakpoint";

const { isMobile, isTablet, isDesktop } = useBreakpoint();
```

## 各层在窄屏下怎么变

| 区域     | 手机端                   | 平板端         | 桌面端             |
| -------- | ------------------------ | -------------- | ------------------ |
| 侧边栏   | 抽屉式，点汉堡展开       | 收窄图标栏     | 常驻展开           |
| 顶栏     | 只留汉堡、标题、头像     | 收起语言与全屏 | 全部展开           |
| 表格     | 取消固定列、分页只留翻页 | 保留固定列     | 完整               |
| 查询区   | 一列，字段全宽           | 两列           | 一行三到四个       |
| 设置面板 | 导航转横排可滑动         | 保持左右分栏   | 左右分栏，导航贴顶 |

## 不做的两件事

**不按像素密度设档。** 六档只看宽度，不看 DPR。2 倍屏与 1 倍屏拿到同一套布局，字号与间距都不缩放——按 DPR 调间距会让同一份设计在不同显示器上不一致。

**不给单个组件写断点。** 断点只在布局层与少数复合件里判断。组件内部如果出现 `@media`，通常说明它应该改成自适应容器，而不是记住几个宽度。
