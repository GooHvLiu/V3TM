# 间距令牌

组件里的内外边距不写像素值，全部走 `@space-*`。这些变量最终编译成 CSS 变量 `--space-*`，一套刻度同时服务 Less 与运行时代码。

## 刻度

| 令牌         | 值   | 典型用途             |
| ------------ | ---- | -------------------- |
| `@space-0-5` | 2px  | 图标与文字的微调     |
| `@space-1`   | 4px  | 标签内边距、密集列表 |
| `@space-1-5` | 6px  | 状态点、紧凑控件     |
| `@space-2`   | 8px  | 控件之间的最小间距   |
| `@space-2-5` | 10px | 按钮组               |
| `@space-3`   | 12px | 卡片内区块间距       |
| `@space-4`   | 16px | 卡片内边距、分组间距 |
| `@space-5`   | 20px | 区块内边距           |
| `@space-6`   | 24px | 区块间距             |
| `@space-8`   | 32px | 页面级分区           |
| `@space-10`  | 40px | 大分区               |
| `@space-12`  | 48px | 页面上下留白         |

刻度是 2px 起步的等比台阶，不是 4 的等差。4 与 8 之间需要 6，8 与 12 之间需要 10——这两处如果不给档位，实际书写时就会随手写 5px、7px、11px，一年下来页面里能攒出二十几种间距。

## 非尺度值一律吸附

历史上散落过 14、18、30 这类值，全部吸附到邻近的 12 / 16 / 32：

| 原值 | 吸附到       | 原因         |
| ---- | ------------ | ------------ |
| 14px | 12px 或 16px | 按语义取近档 |
| 18px | 16px         | 表单行间距   |
| 30px | 32px         | 区块间距     |

吸附后只有两条负偏移保留原值：找回密码卡片的 `-6px`、知识中心抽屉的 `-20px`。负偏移表达的是「压住下面那一层」，不属于间距尺度。

## 守卫

```bash
npm run spacing:check
```

脚本扫描全部 `.vue` 与 `.less`，凡是在 `padding`、`margin`、`gap` 里出现的裸像素值都报错。当前覆盖 148 个 `.vue` 文件、558 处间距，全部走令牌。

## 什么时候可以不用令牌

三种情况：`0`、`100%` 这类非长度值；`-1px` 之类的发丝线偏移；以及确实需要精确对齐的 1px 描边修正。除此之外没有豁免。

## 与断点的关系

间距不随断点缩放。窄屏下减少的是列数、内边距从 16 降到 12，刻度本身不变——同一套刻度在不同宽度下保持一致，页面密度才可控。
